# 修复扩展图标显示为黑色方块

> 状态：待用户确认后执行

## 1. 背景与目标

用户报告：扩展在活动栏的图标显示为**黑色方块**。目标是定位根因并替换为正常显示的图标（已确认方案：**单色 π 轮廓**）。

## 2. 根因分析（证据链完整）

**直接根因**：VS Code 对 activitybar 视图容器图标使用 **CSS `-webkit-mask` 做主题染色**——图标 SVG 的所有 fill 颜色被忽略，只取**轮廓（不透明区域）作为遮罩**，再用主题前景色填充（官方 UX 指南：视图容器图标须为 24×24、单色 #d7dae0；已知 issue microsoft/vscode#195138 同机制）。

**当前图标为何是黑块**：上一轮提交的 `media/pinel-icon.svg`（1254×1254，图片转矢量产物）第一个 path 是**覆盖整个画布的近白色圆角矩形背景**（`fill="#FDFDFD"`，0,0 → 1254,1254）。作为 mask 时整块不透明 → 实心方块；其余 11 个细节 path 全部被背景吞没。浅色主题下活动栏前景色为深色 → **黑色方块**（与用户报告完全吻合）。

**附带发现**：仓库原版 24×24 图标（深色圆角方块 + 金色 π 字）同样会被 mask 成实色圆角方块（背景 rect 也是实心），只是形状规则、尺寸正确所以不显眼——回退原版并非真正修复，故不采用（已与用户确认）。

## 3. 方案设计

### 3.1 新图标：单色 π 字形轮廓

重写 `media/pinel-icon.svg`（路径不变，package.json 仅路径引用无需改动）：

- **24×24 viewBox**，单色填充 `#d7dae0`（官方推荐色，实际显示色由主题决定）。
- **无背景矩形、无 transform、无多色**——纯镂空轮廓，mask 染色下任意主题正常。
- π 字形由三个圆角矩形拼接（fill 轮廓，兼容 VS Code 的 mask 渲染器）：

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" width="24" height="24">
  <g fill="#d7dae0">
    <!-- π 轮廓：顶横 + 左腿 + 右短腿 -->
    <rect x="4" y="4" width="16" height="3.6" rx="1.8"/>
    <rect x="5.4" y="4" width="3.6" height="16" rx="1.8"/>
    <rect x="15" y="4" width="3.6" height="9.5" rx="1.8"/>
  </g>
</svg>
```

几何说明：顶横覆盖 (4,4)-(20,7.6)；左腿 (5.4,4)-(9,20)；右腿 (15,4)-(18.6,13.5)——π 的典型字形（右腿略短）。执行时若视觉比例不佳可微调坐标。
